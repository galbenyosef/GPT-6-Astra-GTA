# Portside — мини-игра с открытым миром

Исследуйте приморский город пешком и на машине, выполните доставку и уходите от полиции. В комплекте готовая игра и исходный код со всеми последними обновлениями: плавная камера в машине, смена дня и ночи, текстуры городских поверхностей и вертолёт, преследующий игрока сбоку.

## Быстрый запуск

Требуются Node.js 22.12 или новее, браузер с WebGL 2, клавиатура и мышь.

1. Установите **LTS-версию Node.js** с [официального сайта](https://nodejs.org/en/download), если Node.js ещё нет.
2. Полностью распакуйте архив и откройте папку `GTA v3 public` → `GTA v3`.
3. В Windows дважды щёлкните **START.cmd**, на Mac — **START_MAC.command**.
4. Дождитесь открытия браузера и нажмите **Play**.

Пошаговый гайд с установкой Node.js, запуском на Windows и macOS и решениями частых проблем: **[ЗАПУСК.md](ЗАПУСК.md)**.

Оставьте окно сервера открытым во время игры. Для остановки нажмите Ctrl+C или закройте это окно. Обычно адрес игры — http://127.0.0.1:5182/. Если порт занят, сервер сам выберет свободный и откроет правильный адрес. Этот адрес также напечатан в окне запуска.

Для запуска из терминала используйте `node serve.mjs --open` в папке проекта. Двойной щелчок по `dist/index.html` не заменяет запуск сервера.

Готовая игра запускается без установки npm-пакетов. После установки Node.js интернет для игры не нужен; аккаунты и API-ключи не требуются. Сервер доступен только на этом компьютере и отдаёт только готовую сборку из `dist`. Игра не отправляет данные на внешние серверы.

## Управление

| Клавиша | Действие |
| --- | --- |
| WASD / стрелки | Движение пешком; газ, торможение и руль в машине |
| Мышь | Поворот камеры |
| Shift | Бег |
| E | Взаимодействие, вход в машину и выход |
| Space | Тормоз машины |
| V | Вид от первого / третьего лица |
| C | Расстояние камеры от третьего лица |
| 1 / 2 / 3 | Нож / пистолет / автомат |
| ЛКМ / ПКМ | Атака / прицеливание пешком |
| R | Перезарядка |
| N | Большая карта |
| Y | Переход к следующей фазе суток |
| L | Включение / остановка автоматической смены суток |
| M | Звук |
| H | Справка |
| T | Повтор миссии |
| Esc / P | Пауза |

Полный цикл дня и ночи длится 12 минут игрового времени. При паузе время останавливается. Y плавно переключает день, закат, ночь и рассвет.

После Play игра захватывает мышь. Esc освобождает курсор; для продолжения нажмите **Back to the city**. Потеря фокуса автоматически ставит игру на паузу.

Чтобы забрать занятую машину, подойдите к водительской двери и нажмите E при подсказке **Pull driver out**. Дождитесь завершения анимации посадки. При пяти звёздах розыска появляется вертолёт: он летит сбоку и впереди. Вертолёт стреляет только по пешему игроку; пока игрок в машине, он только преследует. Наземная полиция продолжает действовать.

## Исходный код и проверки

Для изменения игры откройте терминал в этой папке:

```powershell
npm.cmd ci
npm.cmd test
npm.cmd run dev -- --port 5183 --strictPort
```

Для обновления готовой игры после правок выполните `npm.cmd run build`, затем перезапустите `START.cmd`. На macOS и Linux используйте `npm` вместо `npm.cmd`. Установка зависимостей требует интернета.

В папке `src` находятся исходники, в `tests` — тесты, в `public` — ресурсы, в `dist` — готовая сборка. `serve.mjs` запускает готовую игру без сторонних серверных зависимостей. Лицензии использованных библиотек сохранены в `LICENSES` и перечислены в [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

При дальнейшей раздаче сохраняйте `dist`, исходники, инструкции, файлы запуска и лицензии. Не включайте заново установленные `node_modules`, локальные настройки, журналы, ключи и служебные отчёты.
