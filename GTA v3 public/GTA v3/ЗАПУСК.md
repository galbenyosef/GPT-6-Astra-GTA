# Как запустить GTA v3 на Windows и Mac

Программировать и вводить команды для обычного запуска не нужно. Игра уже собрана: достаточно один раз установить Node.js и открыть файл START для своей системы.

Нужны компьютер с Windows или macOS, браузер с WebGL 2, клавиатура и мышь. Для первого скачивания игры и Node.js нужен интернет. После установки можно играть без интернета. Аккаунты и API-ключи не нужны.

## Шаг 1. Скачайте всю игру

1. Откройте [репозиторий игры на GitHub](https://github.com/Prokopiy8247/GPT-6-Astra-GTA).
2. Нажмите зелёную кнопку **Code**, затем **Download ZIP**.
3. Дождитесь окончания скачивания.
4. Распакуйте архив целиком. В Windows нажмите на ZIP правой кнопкой мыши → **Извлечь всё** → **Извлечь**. На Mac дважды щёлкните ZIP в Finder.
5. В распакованной папке откройте **GTA v3 public**, а внутри неё — **GTA v3**.

В нужной папке рядом лежат `START.cmd`, `START_MAC.command`, `serve.mjs` и папка `dist`. Запускайте игру из распакованной папки. Не запускайте START внутри ZIP и не переносите его отдельно от остальных файлов.

## Windows: установка и запуск

### Один раз установите Node.js

1. Откройте [официальную страницу Node.js](https://nodejs.org/en/download).
2. Выберите версию с пометкой **LTS**, систему **Windows** и установщик **.msi**. Требуется Node.js 22.12 или новее. Большинству обычных ПК подходит **x64**; для компьютера с Windows на ARM выберите **ARM64**.
3. Откройте скачанный установщик. Нажимайте **Next**, примите условия, затем **Install** и **Finish**. Оставьте стандартные параметры, включая добавление Node.js в PATH. Дополнительные инструменты сборки для этой игры устанавливать не нужно.
4. Закройте старые окна запуска игры, если они были открыты.

### Запустите игру

1. В папке **GTA v3** дважды щёлкните **START.cmd**. Если расширения скрыты, файл может называться просто **START** и иметь тип «Сценарий командной строки Windows».
2. Откроется окно с сообщением **«Игра готова»**, затем браузер.
3. Нажмите **Play**. Можно играть!

## macOS: установка и запуск

### Один раз установите Node.js

1. Откройте [официальную страницу Node.js](https://nodejs.org/en/download).
2. Выберите версию **LTS**, систему **macOS** и установщик **.pkg**. Требуется Node.js 22.12 или новее. Если сайт предлагает выбор архитектуры: для Mac с чипом Apple M1/M2/M3/M4 и новее выбирайте **ARM64**, для Mac с Intel — **x64**. Тип процессора указан в меню Apple → **Об этом Mac**.
3. Откройте скачанный `.pkg`. Нажимайте **Продолжить** и **Установить**. Если macOS запросит пароль, введите пароль вашей учётной записи Mac в системном окне установщика.
4. После установки закройте старые окна Terminal, если они были открыты.

### Запустите игру

1. В Finder откройте папку **GTA v3**.
2. Дважды щёлкните **START_MAC.command**.
3. Откроется Terminal с сообщением **«Игра готова»**, затем браузер.
4. Нажмите **Play**.

Если macOS сообщает, что не удалось проверить разработчика, и вы скачали файлы именно из указанного репозитория: после попытки запуска откройте **Системные настройки → Конфиденциальность и безопасность**, найдите сообщение об этом файле и выберите **Всё равно открыть**. Подтвердите открытие только этого файла. [Официальная инструкция Apple](https://support.apple.com/guide/mac-help/open-a-mac-app-from-an-unknown-developer-mh40616/mac).

Если появилась ошибка **«Нет прав доступа» / Permission denied**, архив мог потерять право на запуск файла:

1. Нажмите **⌘ + пробел**, введите **Terminal** и нажмите Enter.
2. Введите `chmod +x ` — с пробелом после `x`, пока не нажимая Enter.
3. Перетащите `START_MAC.command` из Finder в окно Terminal: путь подставится автоматически. Теперь нажмите Enter.
4. Вернитесь в Finder и ещё раз дважды щёлкните `START_MAC.command`.

## Во время игры

Окно запуска должно оставаться открытым. Его можно свернуть. Обычно игра открывается по адресу **http://127.0.0.1:5182/**. Если этот порт уже занят, START сам выберет свободный порт и откроет правильную страницу. Актуальный адрес всегда указан после **«Игра готова»**.

- **WASD / стрелки** — движение и управление машиной.
- **Мышь** — поворот камеры.
- **E** — взаимодействие, сесть в машину или выйти.
- **V** — вид от первого или третьего лица.
- **Y** — следующая фаза суток; **L** — включить или остановить автоматическую смену суток.
- **Esc** — пауза и освобождение курсора. Для продолжения нажмите **Back to the city**.
- **H** — вся справка по управлению.

Для выхода закройте вкладку игры и окно запуска. Можно остановить сервер сочетанием **Ctrl+C** в окне запуска; на Mac это именно клавиша Control, а не Command.

## Если что-то не получилось

| Проблема | Что сделать |
| --- | --- |
| Браузер не открылся | Скопируйте полный адрес после «Игра готова» из окна запуска в адресную строку браузера. |
| «Node.js не найден» | Установите Node.js LTS по инструкции выше и запустите START заново. Если сообщение осталось, перезагрузите компьютер. |
| Сообщение о старой версии Node.js | Установите актуальную LTS-версию с официального сайта. |
| «Не найдена готовая игра в dist» | Скачайте ZIP ещё раз и распакуйте его целиком. START и папка dist должны лежать рядом. |
| Страница не открывается / соединение отклонено | Убедитесь, что окно запуска всё ещё открыто, и используйте адрес именно из этого окна. |
| Чёрный экран или сообщение о WebGL | Обновите браузер и включите аппаратное ускорение в его настройках, затем перезапустите браузер. При необходимости попробуйте другой браузер с WebGL 2. |
| После Play мышь не захватилась | Щёлкните по окну игры и нажмите Play ещё раз. Esc освобождает курсор. |

Для обычной игры **не нужно** выполнять `npm install`, `npm ci` или сборку. Эти команды нужны только тем, кто меняет исходный код; они описаны в [README.md](README.md).
