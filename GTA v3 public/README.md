# GTA v3 — игра, промпты и бенчмарк

В этой папке находится полный комплект материалов:

- **[GTA v3](<GTA v3/>)** — готовая игра, исходники, тесты и файлы запуска.
- **[1. Основной промпт.txt](<1. Основной промпт.txt>)** — основной промпт.
- **[2. Все остальные промпты.txt](<2. Все остальные промпты.txt>)** — дополнительные задания.
- **[GPT6 Astra GTA v3 Benchmark.ods](<GPT6 Astra GTA v3 Benchmark.ods>)** — таблица результатов бенчмарка в формате OpenDocument.

Для запуска откройте папку **GTA v3**. На Windows используйте **START.cmd**, на Mac — **START_MAC.command**. Один раз установите Node.js LTS с [официального сайта](https://nodejs.org/en/download), если он ещё не установлен. После запуска START браузер откроется автоматически: нажмите **Play**.

**[Пошаговая инструкция на русском для Windows и macOS](<GTA v3/ЗАПУСК.md>)** объясняет установку, запуск и решение частых проблем.

Чтобы скачать весь комплект с GitHub, выберите **Code → Download ZIP** и распакуйте архив целиком.
