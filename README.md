# GPT-6 Astra — GTA v3

Полный комплект игры, промптов и результатов бенчмарка находится в папке **[GTA v3 public](<GTA v3 public/>)**.

## Скачать и запустить

1. Нажмите **Code → Download ZIP** вверху страницы репозитория.
2. Распакуйте архив целиком.
3. Один раз установите **Node.js LTS** с [официального сайта](https://nodejs.org/en/download), если Node.js ещё нет. Требуется версия 22.12 или новее.
4. Откройте папку **GTA v3 public → GTA v3**.
5. На **Windows** дважды щёлкните **START.cmd**, на **Mac** — **START_MAC.command**.
6. Дождитесь открытия браузера и нажмите **Play**. Окно запуска оставьте открытым.

**[Подробный гайд на русском для Windows и macOS](<GTA v3 public/GTA v3/ЗАПУСК.md>)** — со всеми шагами установки и решениями частых проблем.

Готовая игра запускается без установки npm-пакетов, аккаунтов и API-ключей. После установки Node.js интернет для игры не нужен.

## Что входит

- **[Игра GTA v3](<GTA v3 public/GTA v3/>)** — готовая сборка, исходники, тесты, запуск для Windows и macOS.
- **[Основной промпт](<GTA v3 public/1. Основной промпт.txt>)**.
- **[Остальные промпты](<GTA v3 public/2. Все остальные промпты.txt>)**.
- **[Таблица бенчмарков](<GTA v3 public/GPT6 Astra GTA v3 Benchmark.ods>)** — файл OpenDocument (.ods).

Игра включает город с пешеходами и транспортом, доставку, полицейские погони до пяти звёзд, вертолёт, виды от первого и третьего лица, текстуры городских поверхностей и смену дня и ночи.

Управление и команды для изменения исходного кода описаны в [README проекта](<GTA v3 public/GTA v3/README.md>). Лицензии сторонних библиотек сохранены в [LICENSES](<GTA v3 public/GTA v3/LICENSES/>) и [THIRD_PARTY_NOTICES.md](<GTA v3 public/GTA v3/THIRD_PARTY_NOTICES.md>).
